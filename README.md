# Hubble Website

A beautiful, responsive website for the Hubble project - a FHIR-compliant terminology microservice for NAMASTE-ICD11 integration.

## 🌟 Features

- **Modern Dark Mode Design** - Inspired by contemporary web design trends
- **Fully Responsive** - Works perfectly on desktop, tablet, and mobile devices
- **Interactive Demo** - Live demonstration of the terminology service
- **Comprehensive Information** - Detailed pages covering all aspects of the project
- **Professional Team Section** - Showcase of team members and expertise
- **Contact & FAQ** - Easy ways to get in touch and find answers

## 📁 Website Structure

```
website/
├── index.html          # Homepage with hero section and overview
├── about.html          # About us, mission, vision, and values
├── solution.html       # Detailed solution overview and features
├── team.html           # Team members and advisory board
├── demo.html           # Interactive demo interface
├── contact.html        # Contact form and FAQ
├── styles.css          # Complete CSS styling
├── script.js           # JavaScript functionality
└── README.md           # This file
```

## 🚀 Getting Started

1. **Clone or Download** the website files
2. **Open** `index.html` in your web browser
3. **Navigate** through the different pages using the navigation menu
4. **Try the Demo** on the demo page to see the terminology service in action

## 📱 Responsive Design

The website is fully responsive and optimized for:
- **Desktop**: 1200px+ (full layout)
- **Tablet**: 768px - 1199px (adjusted grid layouts)
- **Mobile**: < 768px (stacked layouts, mobile navigation)

## 🎨 Customization

### Colors
Edit the CSS custom properties in `styles.css`:
```css
:root {
    --primary-color: #8B5CF6;
    --secondary-color: #EC4899;
    --accent-color: #06B6D4;
    /* ... more variables */
}
```

### Content
- Update team information in `team.html`
- Modify company details in `about.html`
- Change contact information in `contact.html`
- Update demo API endpoints in `script.js`

### Styling
- Modify component styles in `styles.css`
- Add new sections using existing component classes
- Customize animations and transitions
