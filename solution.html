API Endpoints

Comprehensive RESTful API for all functionality

Translation

POST /translate/ Translate NAMASTE to ICD-11
POST /translate/reverse Reverse translation ICD-11 to NAMASTE

Search

GET /autocomplete/ Search and autocomplete
GET /codesystem/namaste Get NAMASTE codes

Data Management

POST /ingest/namaste Upload NAMASTE CSV
POST /bundle/upload Upload FHIR Bundle

System

GET /health Health check
GET /conceptmap/ Get concept maps
