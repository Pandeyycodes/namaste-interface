API Documentation

Integrate Hubble into your healthcare applications

GET /autocomplete/ Search and autocomplete medical terms

Parameters:

  • term (string): Search term
  • limit (integer): Maximum results (default: 20)
  • system (string): Filter by system (optional)

Example Response:

{
  "concepts": [
    {
      "code": "NAM-0010",
      "display": "Hridroga",
      "system": "NAMASTE-Ayurveda",
      "synonyms": ["Heart disease"]
    }
  ],
  "total": 1
}
POST /nlp/ AI-powered diagnosis processing

Request Body:

{
  "diagnosis_text": "Patient has diabetes with heart complications",
  "input_language": "en",
  "doctor_id": "optional"
}

Example Response:

{
  "diagnosis_id": "uuid",
  "original_text": "Patient has diabetes...",
  "processed_text": "Patient has diabetes...",
  "nlp_analysis": {...},
  "ayush_matches": [...],
  "biomedical_matches": [...],
  "confidence_scores": {...}
}
POST /translate/ Translate NAMASTE codes to ICD-11

Request Body:

{
  "source_code": "NAM-0010",
  "source_system": "NAMASTE-Ayurveda",
  "target_system": "ICD-11"
}

Example Response:

{
  "mappings": [
    {
      "target_code": "I25.9",
      "target_display": "Chronic ischemic heart disease",
      "equivalence": "related",
      "confidence": 0.85
    }
  ]
}

Getting Started

Quick start guide for developers

1

Get API Access

Sign up for a free API key to start using Hubble services in your applications.

Request API Key
2

Install SDK

Use our SDKs for easy integration with your preferred programming language.

pip install hubble-sdk
3

Make Your First API Call

Start with a simple search or translation request to test the integration.

from hubble import HubbleClient

client = HubbleClient(api_key="your-api-key")
results = client.search("Hridroga")
print(results)
