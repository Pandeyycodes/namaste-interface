How It Works

Generative AI ranks. The verified dataset supplies every code.

1

Understand the intent

Your natural-language or Hindi query is sent to Gemini along with the full NAMASTE ↔ ICD-11 terminology catalogue as grounding context.

2

Rank, don't invent

The model returns only existing NAMASTE codes ranked by relevance, each with a one-line clinical rationale. It never generates a code.

3

Resolve from source of truth

Each ranked code is joined back to the verified dataset to pull the authoritative TM2 and ICD-11 biomedicine codes — so hallucinated codes are structurally impossible.

4

Always available

If the AI service is unreachable, a local semantic-similarity fallback takes over instantly. The demo never breaks.
